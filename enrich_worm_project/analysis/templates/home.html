WGLA: Worm Gene List Analyzer

一個專為線蟲（Caenorhabditis elegans）設計的基因清單分析工具

工具簡介

WGLA 是一個專業的生物資訊分析工具，用於鑑定線蟲基因清單中顯著富集（Enriched）或缺乏（Depleted）的生物特徵。

透過輸入一群線蟲基因，本工具能夠進行統計分析，找出在您的基因集中顯著出現或明顯缺失的生物特徵，例如：

  • 🧬 Protein Domains - 蛋白質結構域
  • 📊 GO Terms - 基因本體論註釋
  • 🔬 Functional Annotations - 功能性註釋
主要功能
  • Enrichment Analysis - 富集分析
  • Depletion Analysis - 缺乏分析
  • 多種統計校正方法（FDR, Bonferroni）
  • 彈性 P-value 閾值設定
  • 視覺化結果展示（Volcano Plot, Bubble Plot）
  • 支援多種生物特徵資料庫
快速開始
  1. 準備您的線蟲基因清單（WormBase Gene IDs）
  2. 前往 Tool 頁面
  3. 貼上基因 ID
  4. 選擇要分析的生物特徵
  5. 點擊 Analyze 開始分析
開始分析 → 查看使用說明
使用提示
