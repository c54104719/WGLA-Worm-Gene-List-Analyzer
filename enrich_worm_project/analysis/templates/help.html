使用說明

歡迎使用 WGLA！ 本頁面將引導您了解如何使用本工具進行線蟲基因清單分析。

輸入格式說明

支援的基因 ID 格式

本工具接受 WormBase Gene IDs（線蟲基因標準 ID）

正確格式範例：
WBGene00000001
WBGene00000002
WBGene00000003
WBGene00044951
WBGene00077504
輸入規則：
  • 每個基因 ID 一行
  • 也支援空格分隔
  • 自動忽略空白行
  • 不區分大小寫
範例基因清單（用於測試）
WBGene00000001
WBGene00000002
WBGene00000003
WBGene00000004
WBGene00000005
複製上方基因 ID 到 Tool 頁面進行測試

輸出結果說明

統計模型基礎 (Fisher's Exact Test)

本工具使用 Fisher's Exact Test 進行統計檢驗，四格表定義如下：

在該特徵中 不在該特徵中 總計
輸入基因 A B - A B
背景基因 C - A D - C - B + A D - B
總計 C D - C D
參數定義：
  • A: 輸入基因中具有該特徵的基因數
  • B: 輸入基因總數
  • C: 背景中具有該特徵的基因數
  • D: 線蟲基因組總基因數
檢驗類型：
  • Enrichment: alternative='greater'
  • Depletion: alternative='less'
結果表格欄位說明
欄位名稱 說明
Term ID / Name 生物特徵的唯一標識符或名稱（如 Protein Domain ID, GO Term）
Trend 趨勢方向：Enriched 或 Depleted
P-value 統計顯著性（根據選擇的校正方法：None, FDR, Bonferroni）
Log2 Fold Change 公式: Log2(Observed Ratio / Expected Ratio)
正值 = Enriched | 負值 = Depleted
Observed Ratio 輸入基因中具有該特徵的比例 (A / B)
Expected Ratio 背景基因組中具有該特徵的比例 (C / D)
P-value 校正方法
None (Raw P-value)

未經校正的原始 P 值，適用於單一測試或探索性分析。

FDR (Benjamini-Hochberg)

推薦。控制假發現率，適用於多重檢驗，較為寬鬆。

Bonferroni

最保守的校正方法，控制家族誤差率，降低假陽性。

使用流程

Step 1: 輸入基因清單
  1. 前往 Tool 頁面
  2. 在 Textarea 中貼上 WormBase Gene IDs
  3. 每個基因一行或用空格分隔
Step 2: 選擇分析特徵
  1. 勾選要分析的生物特徵類別
  2. 目前支援：Protein Domains
  3. 未來將擴充：GO Terms, Functional Groups 等
Step 3: 執行分析
  1. 點擊 Analyze 按鈕
  2. 後端計算所有統計數據
  3. 前端即時顯示結果
Step 4: 篩選與視覺化
  1. 選擇 P-value 校正方法
  2. 設定顯著性閾值 (0.01 / 0.05 / 0.1)
  3. 查看表格與視覺化圖表

常見問題 (FAQ)

建議使用 FDR (Benjamini-Hochberg)。它在控制假陽性的同時保持較高的檢定力，適合多重檢驗場景。 如果您需要更嚴格的控制，可選擇 Bonferroni。

可能原因：
1. 輸入的基因 ID 格式不正確或無法識別
2. 所選的 P-value 閾值過於嚴格
3. 輸入基因數量太少（建議至少 10-20 個基因）
解決方案：檢查基因 ID 格式、放寬閾值、增加輸入基因數量。

正值 (> 0): 該特徵在輸入基因中富集 (Enriched)
負值 (< 0): 該特徵在輸入基因中缺乏 (Depleted)
絕對值越大: 差異越顯著

沒有嚴格限制，但建議：
- 最少: 10-20 個基因（確保統計顯著性）
- 最佳: 50-500 個基因
- 過多: 超過 1000 個可能導致計算時間較長

如果您有其他問題，請聯繫 開發團隊。
