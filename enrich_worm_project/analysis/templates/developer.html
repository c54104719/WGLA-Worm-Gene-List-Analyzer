開發環境設置
快速開始開發
# Clone repository
git clone https://github.com/cosbi-lab/wgla.git
cd wgla

# 建立虛擬環境
python -m venv .venv

# 啟動虛擬環境 (Windows PowerShell)
. .\.venv\Scripts\Activate.ps1

# 啟動虛擬環境 (Linux/Mac)
source .venv/bin/activate

# 安裝相依套件
pip install -r requirements.txt

# 資料庫遷移
python manage.py migrate

# 啟動開發伺服器
python manage.py runserver
注意： 開發前請確保已安裝 Python 3.8+ 和 pip。
